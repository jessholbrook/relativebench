# Governance

## Protocol changes

Protocol, schema, and metric changes use semantic versions. A protocol version is frozen once response generation begins. Material changes require a new run and may not rewrite an existing published snapshot.

## Benchmark inclusion

A benchmark adapter must document provenance, version, license, scoring code, known contamination risk, and whether its items can be redistributed. Benchmarks are selected for relevance and auditability, not because they favor a model family.

## Transition catalog

Every directed edge includes a public rationale. Maintainers may reject edges that compare unrelated price tiers, modalities, or product surfaces without a credible migration path.

## Result corrections

Published snapshots are append-only. A correction creates a superseding snapshot, retains the original artifact, explains the error, and identifies all affected claims.

## Conflicts of interest

Contributors disclose employment, funding, model access, or evaluation support from providers represented in a result. Provider-supplied results are labeled and require independent reproduction for validated status.

## Disputes

Methodological disputes are resolved against the frozen protocol for the affected run. Improvements apply prospectively. Security, privacy, and data-rights issues may require immediate withdrawal while preserving a public correction notice where lawful.
