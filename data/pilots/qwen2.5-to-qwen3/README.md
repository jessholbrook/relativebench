# Qwen transition pilot

This directory contains the selected candidate configuration and a 12-scenario smoke manifest for:

```text
Qwen2.5-7B-Instruct -> Qwen3-8B
```

The smoke manifest exists to verify category coverage, artifact generation, and statistical plumbing. It is **not** the frozen 120-scenario pilot set and cannot produce a publishable model result.

Activation requires the gates in [`docs/first-pilot-transition.md`](../../../docs/first-pilot-transition.md), including a fixed runtime/hardware profile and incumbent recruitment feasibility.
